# UX Copy Review: thecodeman.net

*Review of the on-page copy across Homepage, Blog, Blog Post, Course, and Ebook pages (captured live 2026-06-20). Audience: .NET developers. Brand voice: practical, confident, peer-to-peer ("one engineer helping another"). Focus below is wording, clarity, and consistency — not layout.*

## TL;DR — the 5 copy fixes that matter most

1. **"Last" → "Latest".** "Check out the last video / last ebook" reads as *final / no more coming*. You mean most recent.
2. **One number for one thing.** Subscribers appear as 20k / 18k / 20,000 / 25,000; reviews as "1000+"; ebook sales as "1250+" on *both* ebooks. Pick one true figure per claim and reuse it.
3. **Sentence case your CTAs.** "JOIN 20K+ ENGINEERS", "RESERVE A SPOT", "CHECK OUT THE LAST EBOOK" shout in all-caps; the rest of the site is sentence case. Make buttons consistent and verb-first.
4. **"Issues" is ambiguous to developers.** "Recent TheCodeMan.NET Issues" reads like GitHub issues/bugs. You mean newsletter issues — say so.
5. **One spelling of your name.** "Stefan Đokić" (hero/badges) vs "Stefan Djokic" (footer). Choose one and use it everywhere.

## 1. Homepage

### Recommended Copy
- **Hero headline**: "Become a better .NET engineer — one tip a week."
- **Hero CTA**: "Join 20,000+ engineers"
- **Section title (testimonials)**: "What .NET developers say about the newsletter"
- **Section title (articles)**: "Latest newsletter issues" *(or "Recent articles")*
- **Sub-CTAs**: "Reserve a sponsor slot" · "Watch the latest video" · "See the latest ebook"

### Issues & Alternatives
| Element | Current | Problem | Recommended |
|---|---|---|---|
| Hero headline | "Become a Better .NET Engineer One Tip Weekly" | Two clauses jammed together, no connector; title-case is heavy. | "Become a better .NET engineer — one tip a week." |
| Hero CTA | "JOIN 20K+ ENGINEERS" | All-caps; number contradicts the "18k+" right below it. | "Join 20,000+ engineers" |
| Social proof | "5.0 · Join 18k+ engineers" | Conflicts with "20K+" CTA and "20,000+" footer. | Use the same figure as everywhere else. |
| Testimonials title | "What did people say about it?" | "it" has no antecedent; past tense feels dated. | "What .NET developers say about the newsletter" |
| Articles title | "Recent TheCodeMan.NET Issues" | "Issues" = bugs/GitHub to a dev audience. | "Latest newsletter issues" or "Recent articles" |
| Sponsor block | "Promote your business to 20,000+ subscribers" | Sits inside a "How can I help **you**" block aimed at developers — audience whiplash (advertiser vs reader). | Move under a clearly separate "For sponsors" framing, or relabel the section "What you'll find here". |
| Video CTA | "Check out the last video" | "last" = final. | "Watch the latest video" |
| Ebook CTA | "CHECK OUT THE LAST EBOOK" | "last" + all-caps. | "See the latest ebook" |
| Footer | "…by Microsoft MVP Stefan Djokic" | Name spelled without diacritics; "Đokić" elsewhere. | Pick one spelling sitewide. |

## 4. Course — Pragmatic .NET Code Rules

The best-written page on the site. Hero ("Make your .NET codebase enforce itself.") and the body ("Stop arguing about code style — let the build do it. Copy, apply, ship.") are excellent. The Before/After list is sharp and concrete. Keep almost all of it.

| Element | Current | Problem | Recommended |
|---|---|---|---|
| Offer line | "Presale – 50% off" (here) vs global bar "40% off" | Two different discounts for the same product. Conflicting offers kill trust and the urgency they're meant to build. | One discount figure, driven from one source. |
| Primary CTA | "Reserve Your Spot" | For a *digital* course with unlimited seats, "reserve a spot" implies false scarcity. | "Get presale access" or "Lock in 50% off". (Keep scarcity for the *price* deadline, which is real, not the seats.) |
| Social proof | "Loved by .NET devs (1000+ reviews)" | A "1000+ reviews" claim is strong; make sure it's defensible (the page shows a handful of testimonials). | If the real number is smaller, say "Rated 4.9 by .NET developers" without the inflated count. |
| Trust strip | "25,000+ newsletter readers" | Conflicts with 20,000 used elsewhere. | One canonical subscriber number. |
| Countdown + "Price goes up at launch – permanently." | — | Great urgency copy. Keep. | — |

## 5. Ebooks — "Design Patterns that Deliver" & "Design Patterns Simplified"

Both headlines are excellent and well-differentiated by audience:
- *That Deliver*: "Stop guessing design patterns. Start shipping the right one." (intermediate)
- *Simplified*: "Design patterns, finally simple enough to actually use." (beginner)

The "Who still wants to read a 500+ page book that costs over $100?" framing is a strong, concrete anchor. Keep these.

| Element | Current | Problem | Recommended |
|---|---|---|---|
| Social proof | "1250+ copies sold" (Deliver) **and** "1250+ developers learning…" (Simplified) | Identical number on two different products reads as a templated placeholder. | Use each product's real figure; if unknown, drop the count and lead with the price/benefit. |
| Nav vs top bar | "AI Tutor" (nav) vs "10 patterns + 2 AI tutors" (top bar) | Singular vs plural for the same feature. | Pick one: "AI Tutor" everywhere, or "AI Tutors (2)". |
| Top-bar pricing | "just $9.95" / "just $32.99" | "just" is good price-softening — consistent across both. Keep. | — |

## Cross-cutting voice & terminology rules (apply once, sitewide)

1. **"Latest", never "last"** for recent content.
2. **One number per claim**: subscribers, reviews, copies sold. Decide the true figure and reuse it.
3. **CTAs = sentence case + verb-first + specific outcome**: "Join 20,000+ engineers", "Get the ebook", "Get presale access" — not all-caps, not "Submit".
4. **"Newsletter issues"**, not bare "Issues", for a developer audience.
5. **One name spelling** (Đokić vs Djokic) and **one product taxonomy** (a thing is either a Course or an Ebook — "Design Patterns That Deliver" is currently filed under Courses but is an ebook).
6. **Scarcity must be honest**: time-limited price = real; "reserve your spot" for unlimited digital goods = not. Anchor urgency to the deadline, not fake seats.

## Localization note (for any future Serbian / multi-language version)
Wordplay like "enforce itself", "while drinking coffee", and "ship the right one" won't translate literally — they'll need transcreation, not translation. Budget ~20–30% text expansion for buttons if you localize; current tight CTAs ("Get the Ebook") will grow.
